# 04: 补救面 — 手动重推 API + 日报页状态/重推入口

**What to build:** 运营者在日报页能看到当期推送到各群的状态(未推送/已推送/失败),并点"重新推送"绕过防重立即再推一次——群里误删消息或某次推送失败后可手动补救,不用等下一期。

**Blocked by:** 03 (自动推送链路)

**Status:** ready-for-agent

- [ ] 手动重推端点:按期触发,显式绕过"已有 success 则跳过"的防重,结果同样落推送记录表
- [ ] 期不存在/无可用 webhook 时返回业务错误码,与现有错误风格一致
- [ ] 日报页展示当期各 webhook 推送状态(读取推送记录)
- [ ] 日报页"重新推送"按钮,失败/成功有用户可见反馈
- [ ] 集成测试:重推绕过防重并新增记录;前端手动验证一次推送成功路径
- [ ] 覆盖率门槛保持通过
